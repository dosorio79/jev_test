# Published experiment results

The [multilingual CX sentiment routing report](cx-sentiment-routing/index.html)
is the curated public artifact from the frozen-policy evaluation performed on
2026-10-20. Its companion aggregate metrics contain no customer comments or raw
provider responses.

The report evaluates Jev 1.13.0, GPT-6 Luna, and a Jev-first hybrid on the same
600-record synthetic held-out test set. The decision threshold was selected on
separate validation data and frozen before this evaluation.

These artifacts are experiment evidence, not a production benchmark or provider
endorsement. Dataset redistribution remains restricted until the original source
and license are verified; see [Dataset provenance and redistribution status](../DATA_LICENSE.md).
